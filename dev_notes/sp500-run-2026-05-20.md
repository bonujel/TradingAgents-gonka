## 4. 典型样例

### 4.1 空流（不可救型，10 例）

`CHD`、`COP`、`FTNT`、`HAS`、`IBKR` 等：

```
[retries=3] ValueError: No generations found in stream.
```

retry 3 次都返回空流。模型对 News Analyst 的特定 prompt 反复拒答（safety
filter / context window / token-budget 等都可能）。**这是当前最大可压缩项**——
后续需要做诊断（捕获 prompt 和 response.usage / response.choices[0].finish_reason）。

### 4.2 Gonka 链 executor bug（4 例）

`CVNA`、`FDX`、`SHW`、`VMC`：

```
[retries=3] APIError: inference: winner inference incomplete (nonce_finished=false)
```

5-19、5-20 各 4 例，**稳态出现**。需要 Gonka 团队跟进。

### 4.3 stalled watchdog（已大幅缓解，仅 1 例）

`SWKS`：

```
[retries=3] APIError: inference: winner stalled waiting for next chunk after 1m30s
```

5-19 是 4 例 retries=0（白名单缺）；5-20 加入白名单后剩 1 例（即使 retry 也救不回），即 **3/4 被救回**。

### 4.4 日期截断（剩 1 例）

`WMB`：

```
[retries=0] ValueError: time data '2026-05-0' does not match format '%Y-%m-%d'
```

LLM 输出 `'2026-05-0'`——日只有 0 一位数（应该是 `'05'`）。当前
`safe_strptime` 不处理这种**完整日期格式但单字段位数错**的情况；要修也行
（加一条 `if len(d) == 1: pad`），但收益只有 1 个 ticker，价值不大。
